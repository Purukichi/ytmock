# ytmock

イラスト・デザイン制作の途中段階で「YouTube に上げたらどう見えるか」を確認するためのシミュレーターです。
A YouTube appearance simulator for checking how your illustration / design looks on the watch page.

`index.html` をブラウザで開くだけで動きます。ビルド・サーバー・外部ライブラリは不要です（完全オフライン動作）。
Just open `index.html` in a browser — no build step, no server, no external libraries (fully offline).

## 機能 / Features

| アイコン | 機能 |
| --- | --- |
| 🖼 画像ボタン / プレーヤーへドラッグ&ドロップ / ペースト | 検証したい画像を動画としてインポート |
| 縦長〜横長の矩形ボタン + スライダー | アスペクト比を変更（9:16 〜 2.4:1、プリセットと連続スライダー）。プレーヤー枠も実際のYouTube同様に伸縮し、16:9より横長では上下黒帯なし・縦長では左右黒帯のみ |
| 画像をドラッグ | 表示範囲の移動（object-fit: cover で見切れる部分の調整。プレーヤーとサムネは個別に調整可能） |
| ☀ / ☾ | ライトモード / ダークモード切り替え |
| ▭（シネマ） | シネマモード / 通常モード切り替え |
| ─●─（シークバー） | ホバー時のシークバー・コントロールの表示 / 非表示 |
| ✎ | 動画タイトルの編集（タイトルを直接クリックしても編集可。おすすめ欄のタイトルと同期） |
| ▭≡（サムネパネル） | サムネイル調整パネルを開閉。拡大プレビュー上でドラッグして位置調整、スライダー / ホイールでズーム（1〜4倍、顔アップなどに）、↺でリセット |
| 数値をクリック | 再生数・高評価数を自由に編集（ピルの幅は内容に合わせて自動伸縮） |
| 📷 | 現在の見た目を **JPG / 1920×1080 (FHD)** で保存 |

- おすすめ欄の先頭にはインポートした画像がサムネイルとして表示されます。実際のYouTubeサムネと同じく常に16:9で、本体のアスペクト比設定とは独立しています（ドラッグで表示範囲を個別調整）。
- それ以外のサムネイルは目に優しい低彩度の単色です。
- 再現パネルは内部的に常に 1920×1080 でレイアウトされ、画面サイズに合わせて自動でスケールされます。どの環境でも同じ見た目・同じスクリーンショットが得られます。

## 構成 / Files

- `index.html` — UI 構造（コントロールバー + YouTube 再現パネル）
- `styles.css` — スタイル(コントロールバーは標準フォント、再現パネルは Roboto / Arial)
- `app.js` — ロジック（アスペクト比計算、ステージスケーリング、SVG foreignObject によるスクリーンショット生成）
